Getting started
=======================

.. note::

   User name
           In this documentation, we will use ``username`` as an alias for a generic user name.

   Project name
	   Overall, it is supposed that you have access to a `project`
	   folder. In this documentation, we consider the generic name
	   ``myproject``, but of course you should adapt it to your
	   specific case.

   Python virtual enviroment name
           Same as above for the name of your
	   python virtual enviroment, which in this documentation will
	   always be ``myenvname``.
